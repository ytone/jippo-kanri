# 実包管理帳 🎯

猟銃所持者向けの実包（じっぽう）管理アプリです。購入・使用の記録、残弾数の管理、火薬類譲受許可証の期限管理をスマホからでも行えます。

## 機能

- **残弾管理** — 弾種ごとの購入・使用を記録し、残弾数をリアルタイムで計算
- **弾種登録** — 口径・種類（スラッグ/散弾/ライフルなど）と在庫アラートを設定
- **許可証管理** — 火薬類譲受許可証の有効期限を管理し、期限切れ前にアラート表示
- **PDF出力** — 警察署提出用の記録簿をPDFとして印刷・保存
- **PWA対応** — スマホのホーム画面に追加してアプリとして使用可能

## 使い方

### オンラインで使う

→ [https://（ユーザー名）.github.io/jippo-kanri/](https://github.com)

### ローカルで使う

`index.html` をブラウザで開くだけで動作します。インストール不要。

```
index.html をダブルクリック → ブラウザで開く
```

## データについて

データはブラウザの `localStorage` に保存されます。サーバーへの送信は一切行いません。

> ⚠️ ブラウザのキャッシュ削除やプライベートモードでは、データが消える場合があります。定期的にPDF出力でバックアップを取ることをお勧めします。

## PDF出力（警察署提出用）

「🖨️ PDF出力」ボタンを押すと、以下の内容をまとめた印刷用ページが開きます。

|節  |内容              |
|---|----------------|
|第１節|火薬類譲受許可証 一覧     |
|第２節|実包 残弾在庫 サマリー    |
|第３節|実包 購入・使用 記録（弾種別）|

印刷ダイアログで「PDFとして保存」を選択してください。PCのChromeまたはSafariでの出力を推奨します。

## 技術構成

- HTML / CSS / JavaScript のシングルファイル構成
- 外部ライブラリ・フレームワーク不使用
- データ保存：ブラウザ localStorage
